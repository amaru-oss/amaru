## Acceptance limits

Evidence levels: launch/session/guards **unit-tested and integration-tested**; native Firefox loopback cookie/CSRF/WebSocket/logout **real-validated**; private publication/ownership **integration-tested on native Linux**; SDK transport **integration-tested with the real auth adapter**, browser execution of the SDK **not validated**.

The fixture WebSocket performs an actual HTTP upgrade and closes on the auth watch; it does not implement Project Event replay. No composed product API, canonical per-user startup/discovery path, `amaru open` executable integration, two-client/two-Project acceptance, or structured logging middleware is claimed. #18 owns composition; #170 must capture auth paths without raw targets, headers or bodies. #92 remains open pending reviewed delivery acceptance. A transport must call `WatchSocket` and stop its watch on socket close; auth guards alone cannot revoke a socket after upgrade.

macOS/Windows native security and Node 22 are **not validated**. Private discovery fails closed outside Linux; no permission fallback is provided. IPv6 Host syntax is tested. This sentence is superseded for the adapter by the [2026-11-13 IPv6 record](2026-11-13-linux-iam-001-ipv6.md), which records a Linux Firefox run on a test-created `[::1]` listener; the composed Platform still binds IPv4 only (see the matrix below). Filesystem fault coverage includes entropy/unsafe-path failures; injected low-level write/close/rename failures and power-loss durability are not established. OS-user trust remains the compact boundary; this does not isolate hostile processes running as the same user. No complete security audit, general release readiness, M3 exit or M4 transition is claimed.

### Verdict for #92

Adapter-level criteria for loopback, token and browser protection have unit, integration and Linux-Firefox evidence as listed. Product-level acceptance, including `amaru open`, composed transport, composed IPv6 and structured auth logging, is not delivered and is owed to #18 and #170. Whether adapter-level evidence closes #92 before #18 composition is a human decision for the product owner. This section does not accept any ADR and does not change the status of ADR-0034, ADR-0060 or ADR-0061.
